# 🏠 RoomMate

자취 생활에 필요한 **재고·유통기한/교체주기 관리, 공과금 N빵 정산, 월간 루틴·일정 캘린더, 대시보드 요약**을 한곳에 모은 웹 애플리케이션입니다.

---

## ✨ 주요 기능

### 1. 대시보드 (`DashboardPage`)

- **핵심 현황 카드**: 7일 이내 임박/만료 품목 수, 미정산 내 부담금 합계, 남은 할 일·루틴 수 요약
- **유통기한·교체 임박 품목**: D-day 기준 정렬 및 만료/경과 뱃지 표시
- **미정산 공과금 & 다가오는 루틴·일정**: 기간 일정(`시작일 ~ 종료일`) 묶음 표시를 포함한 주요 현황 한눈에 확인

### 2. 재고·유통기한 관리 (`ItemsPage`)

- 생필품, 식재료, 상비약, 영양제 통합 관리
- 식재료 보관 구역(`냉장`, `냉동`, `실온`) 및 교체·만료일 빠른 프리셋(`+7일`, `+1개월`, `+3개월`, `+6개월`) 지원
- 카테고리 필터링 및 `-` / `+` 버튼으로 수량 즉시 조절
- 품목별 최저가 검색 링크 연결 및 달력 자동 연동

### 3. 공과금 N빵 정산 (`BillsPage`)

- 청구 월(`YYYY-MM`) 및 납부 예정일(`YYYY-MM-DD`) 지정, 인원수 기준 1인당 정산 금액 자동 계산
- 카카오톡 정산 안내 문구 원클릭 복사 기능
- 정산 완료 토글 시 연동된 달력 일정 완료 상태 동기화

### 4. 달력·루틴 관리 (`CalendarPage`)

- 상단 폼 및 날짜 클릭 모달을 통한 단일/기간 일정 추가 (`당일`, `2일`, `4일`, `7일` 프리셋 지원)
- 주 단위(7일 행)로 끊김 없이 이어지는 기간 일정 바(Range Bar) 렌더링
- 기간 일정 모달에서 **전체 완료 / 이날만 삭제 / 전체 삭제** 지원

### 5. 데이터 저장 및 백업 (`App.tsx`)

- `localStorage` 기반 자동 저장으로 브라우저 새로고침 시에도 데이터 유지
- **백업 저장(JSON 다운로드)**, **백업 불러오기(JSON 업로드)**, **초기 샘플 데이터 복원** 지원

---

## 🛠 기술 스택

- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **State & Persistence**: React Hooks (`useState`, `useEffect`, `useMemo`), Web Storage (`localStorage`), JSON Export/Import

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```
